# 예감 스타일 가이드 — C안 (확률 눈금) v1

작성: Claude Cowork · 2026-10-16 · 기획자 확인 대기
캔버스 원본: "예감 디자인 리뉴얼" 캔버스의 "C안 스타일 가이드" 보드

화면을 만들거나 고칠 때 이 문서를 따른다. 토큰 이름은 `src/app/globals.css`의 지금 이름을 그대로 쓰고 값만 바꾼다. **NEW**는 새로 추가하는 이름.

## 1. 콘셉트
- 확률을 고르는 서비스라는 점이 화면에서 바로 보이게: 0~100 눈금, 예측 전 "??%".
- 차가운 흰 바탕 + 남색 글자 + 파랑 강조. 예 = 파랑, 아니오 = 주황 (항상 "예/아니오" 글자 함께).
- 구분은 그림자보다 면 색·1px 선·간격으로.

## 4. 모양
- 모서리: 6 작은 칩 · 10 탭/입력/메뉴 줄 · 12 버튼 · 18 카드/패널 · 24 핫이슈/큰 상자 (`ui.ts card`는 18로)
- 간격: 4의 배수. 4 · 8 · 12 · 16 · 20 · 28 · 32 · 44
- 그림자: 기본은 없음 + 1px 선. small = 마우스 올림·펼침 메뉴, large = 대화상자·☰ 패널. 다크는 그림자 대신 한 단계 밝은 면.
- 폭: 홈 3단 최대 1280 (왼쪽 220 · 오른쪽 300 · 사이 32) / 질문 상세 최대 1060 (예측 패널 340) / 그 밖 1060
- 1024 미만: 왼쪽 메뉴 → 가로 분야 탭, 사이드바 → 본문 아래. 390: 좌우 16, 위쪽 ☰, 하단 탭 없음. 누르는 곳 최소 44×44.

## 5. 부품
- 버튼: 기본(brand 채움 + 흰 글자), 보조(bg-alt 채움), 예(yes + 흰 글자), 아니오(no + on-no 글자), 작은 버튼 32px, 위험(negative-strong)
- 칩: 분야(bg-alt), 새 질문(yes 채움), 객관식 N·이슈 이름(yes-soft + yes-ink), 여론 변동 큼·결과 아니오(no-soft + no-ink)
- 메타: D-N(num-s, 3일 이하 caution), 참여자(사람 아이콘 + 숫자, aria-label "N명 예측"), ▲▼(yes-ink / no-ink), 잠금("참여하면 보여요"), 칸 제목 옆 ⓘ
- 확률: OX 눈금(아니오 track → 가운데 50 → 예 track, 모두 위치 = 진한 막대, 내 위치 = 동그라미), 객관식 막대(yes 채움), 예측 전은 빗금 막대 + "참여하면 보여요", 핫이슈는 큰 "??%"
- 카드: surface + 1px line + 18 모서리, 안쪽 20 (모바일 16~18)
- 댓글: 댓글마다 카드. 머리줄 = 프로필(티어 색 테두리) · 닉네임 · ◆티어 · 시간 / 오른쪽 진영 알약(예측 전 "진영은 예측 후 공개") / ⋯(신고). 아래 줄 = 리액션 3종 · 답글. 답글은 들여쓴 회색 상자.

## 6. 지킬 것
- "포인트·배당·수익·베팅" 금지 → "점수·예측". 돈·경품 느낌의 그림 금지.
- 예측 전 가림: 확률·막대·▲▼·댓글 진영은 숫자가 새지 않게.
- 카드 한쪽에만 색 띠 넣는 강조 테두리 금지.
- 남은 기간 D-N(하루 안 D-day, 마감 "마감"), 정확한 마감 시각은 보조로 함께. 참여자는 사람 아이콘 + 숫자.
- 칸 제목 번호 없음, 설명은 ⓘ 툴팁.
- prefers-reduced-motion: 롤링 자동 넘김·뱃지 움직임 멈춤.
- 다른 회사 로고·전용 서체·이름 금지. 서체는 OFL만.
