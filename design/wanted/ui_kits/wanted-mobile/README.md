# Wanted Mobile UI Kit

iOS-flavored mobile recreation of the Wanted job-search app.

## Components
- `AppBar.jsx` — logo + icon actions
- `JobRow.jsx` — list row: thumbnail, title, company, meta, bonus, bookmark
- `TabBar.jsx` — bottom tab bar (홈 / 매칭 / 이력서 / 저장 / 더보기)
- `ios-frame.jsx` — device chrome (starter component)

## Open
`index.html` for the home screen mocked inside an iOS device.
