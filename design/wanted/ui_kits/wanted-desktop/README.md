# Wanted Desktop UI Kit

A high-fidelity recreation of the Wanted job-board home (career.wanted.co.kr-style).

## Components
- `TopNav.jsx` — sticky logo + nav + iconbuttons + sign-in CTA + category sub-bar
- `Hero.jsx` — full-bleed dark hero with eyebrow, headline, sub, primary + ghost CTA
- `FilterBar.jsx` — pill chips (sticky filter row)
- `JobCard.jsx` — square thumbnail + title + company + meta + bonus

## Open
`index.html` for an interactive home view. Designed at 1280px wide.
