# C안 리뉴얼에 필요한 기능 작업 요청 (Cowork → Claude Code)

작성: Claude Cowork (디자인 담당) · 2026-10-16

## 기획자 확정 사항

- 새 디자인은 **C안(확률 눈금)**이다. 예=파랑 / 아니오=주황, 항상 "예/아니오" 글자를 함께 표시한다.
- PC는 **왼쪽 메뉴 · 가운데 콘텐츠 · 오른쪽 사이드바** 3단 구성.
- 가운데 칸 구성은 **지금 실서버 홈 그대로**: 핫이슈 묶음(롤링) → 지금 여론이 움직이는 질문 → 어제 판정된 질문 → 곧 마감되는 질문(카드 격자) → 새로 공개된 질문(카드 격자). 모양만 C안으로.
- **핫이슈 카드 = "섞은 히어로"**: [사진] [3줄 맥락 · 분야 · 질문 제목 · 롤링 점 · 참여자 · D-N] [오른쪽 큰 확률 박스]. 확률 박스는 예측 전 "??%" + 자물쇠 "참여하면 보여요", 예측 후 실제 확률 + 24시간 변화량. 박스 아래 "예측하러 가기" → 질문 상세로 이동.
- 홈 카드에서 바로 예측하기, 정렬 버튼은 **하지 않는다**.
- **남은 기간은 사이트 전체에서 D-N** (`dDay`: D-5, D-15 / 하루 안이면 D-day / 마감되면 "마감"). 정확한 마감 날짜·시각 줄은 보조 정보로 함께 유지한다.
- **참여자 수는 사이트 전체에서 사람 아이콘 + 숫자** (`Participants`). "N명 예측" 같은 글자 표기는 화면에 쓰지 않는다 (화면 낭독용 aria-label만).

화면 모양은 Cowork가 `design` 브랜치에서 바꾼다. 아래는 데이터가 필요해서 Claude Code에 요청하는 것이다.

## 진행 방식

1. Claude Code가 `develop`에서 아래를 구현한다. **마크업은 최소한으로** (기존 `ui.ts` 클래스로 충분). 최종 모양은 Cowork가 입힌다.
2. 끝나면 `develop`을 `design`에 합쳐 두고 기획자에게 알린다.
3. CLAUDE.md를 맨 아래 내용대로 고친다.

부품·props 이름은 제안대로 해 주면 Cowork가 바로 이어서 작업할 수 있다. 바꿨다면 커밋 메시지에 적어 주기.

## 1. PC 왼쪽 메뉴 + 분야별 진행 중 질문 수

**화면**
- PC(lg, 1024px 이상) 홈에서 상단 분야 탭 대신 **왼쪽 세로 메뉴**.
  - 위: 홈 · 랭킹 · 내 예측 (현재 화면 강조)
  - 아래: "분야" 제목 + 핫이슈 · 9개 분야, 분야마다 오른쪽에 **진행 중 질문 수** (핫이슈 행은 숫자 없음). 현재 분야 강조.
- 1024px 미만은 지금처럼 가로로 넘기는 분야 탭 유지.
- 적용 범위: 홈(`/`, `/?category=…`). 다른 화면은 지금 헤더 그대로.
- 3단 폭: 왼쪽 220px · 가운데 · 오른쪽 사이드바 300px, 전체 최대 1280px (지금 1060px에서 넓힘). 오른쪽 사이드바 내용(내 시즌·트렌딩 TOP 5·판정 예정)은 그대로.

**데이터**
- 분야별 진행 중 공개 질문 수. 홈은 이미 진행 중 질문 목록(`open`)을 받으므로 거기서 세면 되고 새 쿼리는 필요 없다고 봄. 비공개 질문은 세지 않음.

**부품 제안**
- `src/components/CategoryRail.tsx` (서버 부품) — props: `active: Category | null`, `counts: Record<Category, number>`
- 홈에서만 폭을 넓힐 수 있게 `PageShell`에 폭 옵션 (예: `wide?: boolean`)

## 2. 내 예측(`/me`) 진행 중 탭에 참여자 수

- 지금 `/me`는 판정 완료 탭에서만 `getBoards`를 불러서, 진행 중 탭에는 참여자 수 데이터가 없다.
- 진행 중 탭 목록에도 질문별 `board`(최소 `participants`)를 넘겨 주면, Cowork가 각 줄에 사람 아이콘 + 숫자와 D-N을 붙인다.
- 여론 공개 규칙은 그대로 (내 예측 목록은 본인이 예측한 질문이라 집단 확률을 보여도 되는 상태지만, 보여줄지는 Cowork 시안에서 정하고 지금은 참여자 수만 필요).
