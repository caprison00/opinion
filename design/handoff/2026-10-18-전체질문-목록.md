# 전체 질문 목록 화면 + 홈 "더보기" (Cowork → Claude Code)

작성: Claude Cowork · 2026-10-18
시안: 캔버스 "C안 · 전체 질문 목록" 줄 (PC·모바일, 분야 탭·정렬 드롭다운 눌러 볼 수 있음)

## 기획자 요청
- 홈의 "곧 마감되는 질문", "새로 공개된 질문" 칸 제목 오른쪽에 **더보기** 링크.
- 누르면 **등록된 전체 질문 목록** 화면. 위에 **전체 탭 + 9개 분야 탭**, 오른쪽에 **정렬 드롭다운**.

## 화면 (시안 기준)
- 주소 제안: `/questions` (질문 상세 `/questions/[id]`의 목록). 상단 메뉴는 일반 헤더, 폭 1060px.
- 순서: ← 홈 / 제목 "전체 질문" → 분야 탭 줄(가로로 넘김, 탭마다 질문 수) → 선 → 왼쪽 **상태 전환 [진행 중 N | 마감·판정 N]** · 오른쪽 정렬 드롭다운 → 카드 격자(PC 3열 · 태블릿 2열 · 휴대폰 1열, `QuestionCard`) → 아래 "질문 더 보기" 버튼.
- 정렬 (상태마다 다름):
  - 진행 중: **마감 임박순(기본)** · 새로 공개된순 · 참여 많은순 · 여론 변동 큰순
  - 마감·판정: **최근 판정순(기본)** · 참여 많은순 · 적게 맞힌순(적중 비율 낮은 순)
- 마감·판정 카드 아래쪽: 판정됨 → "결과 ○○" 칩(아니오는 주황, 그 밖은 파랑) + "단 38%만 맞혔어요" / "71%가 맞혔어요" (홈 어제 판정 카드와 같은 문구), 마감·판정 대기 → "판정 대기" 칩 + "10.20 (화) 판정 예정". 무효(void) → "무효 처리" 칩. 오른쪽 위 D-N 자리는 "판정" / "마감".
- 홈 더보기 링크: 곧 마감 → `/questions?sort=closing`, 새로 공개 → `/questions?sort=new`
- 빈 분야: `EmptyState` "○○ 분야에 진행 중인 질문이 없어요." / "○○ 분야에 마감·판정된 질문이 없어요."

## 데이터·기능 요청
- 주소 값: `?status=open|done&category=<분야>&sort=…` (+ 더 보기용 `&page=` 또는 `&limit=`). 잘못된 값은 기본값(status=open).
  - status=open의 sort: `closing|new|popular|moving` / status=done의 sort: `resolved|popular|hard`
- 목록 대상: 공개 질문만 (비공개 제외).
  - **진행 중** = 홈 `open`과 같은 기준
  - **마감·판정** = 마감됐거나(closed) 판정됐거나(resolved) 무효(void)인 공개 질문 (기획자 확정: 함께 보여준다)
- 마감·판정 정렬: resolved = `resolved_at`(없으면 `close_at`) 내림차순, popular = 참여자 수, hard = `board.hitRate` 낮은 순(판정된 질문만, 없으면 뒤로).
- 마감된 질문은 누구나 집단 확률을 볼 수 있다는 기존 규칙 그대로 (여론 공개 규칙).
- 정렬:
  - closing = `close_at` 오름차순
  - new = `open_at` 내림차순
  - popular = `board.participants` 내림차순
  - moving = 24시간 변화량 큰 순 (홈 "지금 여론이 움직이는 질문"과 같은 기준). 여론 공개 규칙은 카드에서 그대로 (예측 전엔 숫자 없음).
- 분야 탭별 질문 수는 **지금 고른 상태 기준** (진행 중이면 진행 중 수, 마감·판정이면 그 수). 전체 탭은 합계. 상태 전환 버튼에도 각 총 개수.
- 한 번에 12개, "질문 더 보기"로 12개씩 추가 (서버에서 page로 받아도 되고, 처음에 다 받아 화면에서 잘라도 됨 — 질문 수가 적어서 어느 쪽이든 OK).
- 정렬 드롭다운은 링크 목록(각 항목이 `<a href>`)으로 만들어 주면 새로고침·공유에도 정렬이 유지됨. 펼침/닫힘은 작은 클라이언트 부품.
