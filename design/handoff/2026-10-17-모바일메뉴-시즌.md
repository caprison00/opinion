## 요청: `AccountInfo`에 한 묶음 추가
`Header.tsx`의 `getAccount`가 이미 `profile_stats`로 받는 값이라 새 쿼리는 필요 없다고 봄.

```ts
seasonStats: {
  key: string;             // s.season ("2026-10") — D-N 계산용
  total: number;           // s.season_total
  count: number;           // s.season_count
  rank: number | null;     // s.season_rank
  eligible: number | null; // s.season_eligible
  topPct: number | null;   // topPercent(rank, eligible), 순위 없으면 null
};
```
- 이름은 이대로 해 주면 Cowork가 바로 이어서 작업한다 (바꾸면 커밋 메시지에 적기).
- 기존 `season` 한 줄 글자는 PC 펼침 메뉴에서 계속 쓰니 그대로 둔다.
- D-N은 Cowork가 화면에서 `key`로 계산, `SEASON_MIN`은 `@/lib/tiers`에서 가져온다 (타입만 import하는 파일이라 클라이언트에서 써도 됨, 확인함).
